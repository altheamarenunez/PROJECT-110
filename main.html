— ABOUT QUOTEZY —

Quotezy is a simple Random Quote Generator that helps users discover meaningful quotes quickly and easily.

01

OUR PROJECT

The goal is simple.

Instead of searching through different websites, users can click one button to receive a random quote from a public API.

We created Quotezy to make discovering quotes simple and enjoyable while demonstrating how HTML, CSS, JavaScript, and API integration work together.

HOW IT WORKS —

Three simple steps.

01

Click

Press the Get a Quote button to request a random quote.

02

Fetch

JavaScript sends a request to the public API to retrieve a quote.

03

Discover

The website displays the quote and its author's name.

— THE API —

Powered by a public quote API.

API used: DummyJSON Quotes
Documentation: dummyjson.com/docs/quotes
